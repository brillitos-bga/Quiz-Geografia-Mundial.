# Quiz de Geografía Mundial

## Descripción
Quiz de Geografía Mundial es un juego interactivo desarrollado en Python que permite poner a prueba los conocimientos sobre diferentes lugares del mundo mediante preguntas de opción múltiple.

## Objetivo
Crear un juego educativo que permita aprender y reforzar conocimientos de geografía de una manera sencilla y entretenida.

## Características
- Contiene 10 preguntas de geografía.
- Selecciona 5 preguntas aleatorias en cada partida.
- Cuenta con 5 vidas.
- Cada pregunta tiene un límite de 5 segundos para responder.
- Otorga 10 puntos por cada respuesta correcta.
- Muestra los resultados al finalizar el juego.
- Registra el tiempo total de la partida.
- Cuenta con una interfaz gráfica.

## Tecnologías utilizadas
- Python
- Tkinter
- Módulos random y time

## Archivos del proyecto
- `python main.py`: contiene el código principal del juego.
- `preguntas.txt`: contiene las preguntas, opciones y respuestas correctas.

## Requisitos
- Tener Python instalado.
- Contar con los archivos del proyecto en la misma carpeta.

## Cómo ejecutar el programa
1. Descargar los archivos del repositorio.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar el codigo.
4. Se abrirá la ventana del juego.
5. Presionar el botón "Empezar juego" para comenzar.
